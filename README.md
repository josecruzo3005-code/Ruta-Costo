# RutaCosto 🇨🇴
Aplicación Android para estimar y aprender el costo real de viajar en Colombia.

## Primera versión funcional
- Ubicación del teléfono para completar el origen.
- Cálculo de combustible.
- Peajes.
- Costo total.
- Costo por kilómetro.

## Próximas etapas
1. Vehículos y consumo personalizado.
2. Rutas reales y alternativas.
3. Peajes por categoría y tarifa vigente.
4. Historial de viajes.
5. Costos reales y predicción personalizada.
6. Navegación.
